# ITOM v1.2.0-rc.1 Release Notes

Release date: 2026-08-27
Channel: release candidate (local UAT only; not released to IDC)

## Added

- Added an About page for product version, release status, release date, highlights, and release history.
- Added About to the user menu and a software-version entry with candidate highlights to the login footer.
- Added Developer & Legal to Interface & Branding for developer, vendor, copyright, website, support, license, and third-party-notice presentation.
- Added public read-only endpoints for the current version and release notes.

## Engineering governance

- The Git-controlled `release/current.json` pointer and immutable manifests are the software-version source of truth.
- FastAPI/OpenAPI, health checks, and the frontend build consume the same release manifest.
- Backend and frontend images carry OCI product-version, Git-revision, and release-date labels; release scripts verify the manifest, labels, and health-endpoint version.
- CI validates SemVer, the current pointer, bilingual release notes, and frontend-package consistency.

## Data and permission impact

- No database table, column, migration, or business-data rewrite is introduced.
- Version and release notes are public read-only information. Public APIs do not expose Git SHA, image digest, repository, or database information.
- Aily/MCP identity, tools, domain services, RBAC, and audit boundaries are unchanged.

## Current boundaries

- Per-user release-note acknowledgement is not stored yet.
- IDC deployment history and image digests remain governed by the existing release workflow.
