# ITOM v1.2.0-rc.1 更新日志

发布日期：2026-08-27
通道：候选版本（仅用于本地 UAT，尚未发布 IDC）

## 新增

- 新增“关于系统”页面，集中展示产品版本、版本状态、发布日期、更新摘要和历史版本。
- 用户头像菜单新增“关于系统”；登录页底部增加软件版本入口和候选版本摘要。
- “界面与品牌”新增“开发者与法律”配置，可维护开发者、厂商、版权、官网、技术支持、许可及第三方开源声明。
- 新增公开只读版本接口，供前端读取当前版本和更新日志。

## 工程治理

- Git 管理的 `release/current.json` 与不可变版本清单成为软件版本唯一事实源。
- FastAPI/OpenAPI、健康检查和前端构建共用同一版本清单。
- 前后端镜像增加 OCI 产品版本、Git 修订和发布日期标签；发布脚本校验清单、镜像标签及健康接口版本一致性。
- CI 校验 SemVer、当前版本指针、中英文更新日志和前端包版本一致性。

## 数据与权限影响

- 不新增数据库表、字段或迁移，不改写任何业务数据。
- 版本和更新日志为公开只读信息；Git SHA、镜像摘要、仓库和数据库信息不通过公开接口返回。
- Aily/MCP 身份、工具、领域服务、RBAC 和审计边界不变。

## 当前边界

- 尚未记录用户对更新日志的阅读状态。
- IDC 部署历史与镜像摘要继续由现有发布流程管理。
